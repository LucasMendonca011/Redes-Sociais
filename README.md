# Redes Sociais

Projeto de página inicial que reúne atalhos para redes sociais em uma interface inspirada na tela de um celular. Ao selecionar um ícone, a página correspondente é exibida dentro do mockup; o botão **ACESSE** abre o perfil ou canal vinculado.

## Redes disponíveis

- YouTube
- GitHub
- Instagram
- X (Twitter)
- Facebook

## Como executar

O projeto é estático e não requer instalação de dependências ou etapa de compilação.

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Se preferir, sirva a pasta com qualquer servidor HTTP local e acesse `index.html`.

## Estrutura do projeto

```text
.
├── index.html          # Página principal e navegação entre as telas
├── home.html           # Tela inicial do mockup
├── instagram.html      # Tela do Instagram
├── facebook.html       # Tela do Facebook
├── github.html         # Tela do GitHub
├── twitter.html        # Tela do X (Twitter)
├── youtube.html        # Tela do YouTube
├── estilos/
│   ├── style.css       # Layout da página principal
│   └── social.css      # Estilos das páginas das redes
└── imagens/            # Moldura, fundo, ícones e imagens das telas
```

## Tecnologias

- HTML5
- CSS3
